Device Management
Add, configure, and manage IoT devices

Adding a Device

  1. Go to Users → select a user
  2. Click Add Device
  3. Enter device name, type, and hardware ID
  4. Set the secret key used for authentication
  5. Save — device appears in the appropriate dashboard

Device Types

  • Soil Saathi — NPK / pH sensors
  • AtmoSense — weather sensors
  • Soil Life — bio-activity sensors
Each device requires a unique hardware ID and matching secret key configured on the physical device firmware.

API Data (Readings)

  • Each device stores a list of API records — each record is one sensor reading with all its fields.
  • Records can be edited from the API overview page → Edit button per row.
  • Set alert thresholds per API — if readings exceed the threshold, a notification is triggered.
  • View chart of readings over time from the API overview page.

Versions & Firmware OTA
Manage app/firmware releases — staff & superuser only

Managing Versions

  1. Open Versions from the sidebar
  2. Click Add Version
  3. Enter version string (e.g. v1.2.0)
  4. Upload file: .zip, .apk, .rar, or .tar.gz
  5. Add release notes in Description
  6. Check Active to make it the OTA target
  7. Save — devices will detect the update automatically
Only one version can be active at a time. Marking a new version active will be blocked until the previous one is deactivated.

OTA Update Flow

  • 1
    Device calls GET /versions/api/check-active-version/?version=vX.Y.Z
  • 2
    If update=1 is returned, device fetches file from /versions/api/download-version/
  • 3
    File is streamed with correct MIME type (zip / apk / rar / gzip)
  • 4
    Device installs update and reports new version on next check
Version management requires staff or superuser Django permissions. Regular users cannot access this section.

Notifications & Thresholds
Get alerted when devices exceed defined limits
  • Set a max API call threshold per device — e.g. alert when more than 500 readings in a day.
  • When a device crosses the threshold, a notification is created and appears in the Notifications section.
  • Mark notifications as read to dismiss them from the badge count.
  • Manage thresholds from the API Overview page → Set Threshold.

Device & Firmware API Reference
Complete endpoint documentation for device integrations — authentication, data submission, GPS, OTA firmware updates and more.

Device Authentication
Devices authenticate using a hardware ID + secret key and receive a base64-encoded session token used in all subsequent calls.
OTA Firmware API
Devices poll /versions/api/check-active-version/ and download updates — no authentication required for firmware endpoints.
Account & Settings
Passwords, profile, and access control
  • Change your password from User Details → Change Password.
  • Logout is always accessible at the bottom of the sidebar.
  • Admin-only sections (Versions, User management) require Django staff or superuser status.
Tips & Best Practices
Get the most out of ArkaShine
Keep only one active version
Always deactivate old firmware versions before marking a new one active, to avoid update confusion on the device side.
Test device credentials first
Use the /api/authenticate/ endpoint to verify the device ID and key before deploying to the field.
Set thresholds early
Configure API call thresholds as soon as a device is deployed so you are notified of unusual activity immediately.
Export regularly
Download PDF or CSV reports periodically for offline record-keeping and compliance audits.
